한 줄 요약 — catmoa는 무료 오픈소스(MIT) 프로그램입니다. 마음껏 쓰되, 결과는 등록 전에 꼭 확인해 주세요. 외부 서비스(LLM 공급자·Google)의 약관은 각 서비스의 것을 따르며, 개발자는 앱 사용으로 생긴 손해에 책임지지 않습니다.

1. 약관의 적용

이 약관은 catmoa(이하 "앱")를 내려받아 설치·실행하거나 안내 웹사이트를 이용하는 모든 사용자에게 적용됩니다. 앱을 설치·실행하면 이 약관과 개인정보처리방침에 동의한 것으로 봅니다. 동의하지 않으면 앱을 사용하지 마시고 삭제해 주세요.

2. 서비스의 성격

  • 앱은 교사 해커톤에서 시작된 개인 오픈소스 프로젝트이며, 상업 서비스가 아닙니다. 요금·구독·광고가 없습니다.
  • 앱은 사용자의 컴퓨터에서 실행되는 도구이며, 개발자는 계정·서버·데이터 보관 서비스를 제공하지 않습니다.
  • 앱은 예고 없이 기능이 바뀌거나 개발·배포가 중단될 수 있습니다.

3. 라이선스

앱의 소스 코드와 배포 파일은 MIT 라이선스로 제공됩니다. 라이선스 조건에 따라 자유롭게 사용·복제·수정·재배포할 수 있으며, 소프트웨어는 "있는 그대로(AS IS)" 제공됩니다.

4. 외부 서비스와 사용자의 책임

앱은 사용자가 설정한 외부 서비스와 통신합니다. 각 서비스의 이용은 해당 서비스의 약관과 요금 정책을 따르며, 계정·API 키·비용은 사용자가 관리합니다.

  • LLM 공급자: Anthropic, OpenAI, 또는 로컬 Ollama. API 사용 요금은 사용자의 공급자 계정에 청구됩니다.
  • Google: Google 서비스 약관. 앱은 사용자가 로그인한 본인 계정의 캘린더·태스크에만 접근합니다.
  • 쿨메신저(선택 기능): 사용자 PC의 로컬 데이터를 읽기 전용으로 참조합니다. 소속 기관의 규정에 따라 이용 가능 여부를 확인하는 것은 사용자의 책임입니다.

사용자는 앱에 넣는 자료에 대해 처리 권한이 있어야 하며, 학생·학부모 등 제3자의 개인정보가 포함된 자료를 외부 LLM으로 보내기 전에 소속 기관의 개인정보 보호 지침을 확인해야 합니다.

5. AI 추출 결과에 대한 안내

  • 일정 추출은 AI(LLM)가 수행하며 날짜·시간·제목이 틀리거나 누락될 수 있습니다. 앱은 등록 전에 검토 창을 제공하며, 최종 확인과 등록 결정은 사용자가 합니다.
  • 앱이 만든 캘린더 이벤트·태스크·알람으로 인한 일정 착오, 누락, 중복에 대해 개발자는 책임지지 않습니다.

6. 금지 사항

다음 목적으로 앱을 사용할 수 없습니다.

  • 타인의 Google 계정이나 자료에 권한 없이 접근하는 행위
  • 외부 서비스(LLM 공급자, Google)의 약관이나 관련 법령을 위반하는 행위
  • 앱의 이름·아이콘을 이용해 공식 서비스인 것처럼 오인하게 하는 행위(MIT 라이선스가 허용하는 재배포는 제외)

7. 보증의 부인 및 책임의 제한

앱은 어떠한 명시적·묵시적 보증도 없이 "있는 그대로" 제공됩니다. 관련 법령이 허용하는 최대 범위에서, 개발자와 기여자는 앱의 사용 또는 사용 불능으로 인해 발생하는 직접·간접·부수적·결과적 손해(데이터 손실, 일정 누락, API 요금, 업무 지장 등)에 대해 책임을 지지 않습니다.

8. 약관의 변경

약관이 바뀌면 이 페이지와 GitHub 저장소의 변경 이력에 반영합니다. 변경 후에도 앱을 계속 사용하면 변경된 약관에 동의한 것으로 봅니다.
