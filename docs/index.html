🐾 첫 릴리스 준비 중이에요! 곧 이 자리에 다운로드 링크가 생깁니다.
그동안은 아래 소스에서 실행으로 미리 써 볼 수 있어요.
처음 실행할 때 경고가 떠요
  • macOS — "악성 코드가 없음을 확인할 수 없음" 경고가 뜨면 (서명·공증 전이라 정상이에요. macOS 15부터는 우클릭 → 열기가 통하지 않습니다):
    • 경고 창에서 완료 → 시스템 설정 → 개인정보 보호 및 보안 → 아래쪽 "catmoa"이(가) 차단되었습니다 옆 그래도 열기 → 비밀번호/Touch ID. 한 번만 하면 돼요.
    • 또는 터미널에서 xattr -cr /Applications/catmoa.app (앱을 둔 경로로)
  • Windows: 브라우저가 "안전하지 않은 파일"이라 하면 유지, 실행 시 SmartScreen 창에서 추가 정보 → 실행. (단일 실행 파일이라 첫 화면까지 몇 초 걸려요)
  • Linux: tar xzf catmoa-linux-*.tar.gz && ./catmoa/catmoa
소스에서 실행하기 (개발자용) 
git clone https://github.com/progh2/catmoa.git
cd catmoa
./run.sh      # macOS / Linux
run.cmd       # Windows
  • Python 3.11 이상 필요. 가상환경과 의존성 설치는 스크립트가 알아서 해요.

🐾첫 설정은 1분이면 충분

고양이를 우클릭 → 설정

  1. LLM 탭 — 공급자 선택 → API 키(또는 Ollama 주소) → 모델 목록 불러오기 → 연결 테스트
  2. Google 탭 — 로그인 → 브라우저에서 계정 선택 → 끝
  3. 일반 탭 (선택) — 기본 대상(캘린더/태스크), 기본 알람 시간, 인박스 목록명
  4. 쿨메신저 탭 (선택, Windows) — 사용 켜기, 확인 간격(초)

🐾개인정보는 이렇게 다뤄요

별도 서버가 없습니다. 데이터는 내 PC ↔ LLM ↔ Google 사이에서만 오갑니다.

  • 입력한 문서·이미지·쪽지 내용은 내가 선택한 LLM 공급자로만 전송돼요. 외부 전송이 걱정되면 로컬 Ollama를 고르세요.
  • 쿨메신저 DB는 읽기 전용 복사본으로만 접근하며 원본을 건드리지 않아요.
  • Google 토큰은 OS 키체인(macOS Keychain / Windows Credential Manager / Linux Secret Service)에 저장돼요.
